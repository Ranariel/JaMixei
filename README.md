# Ja Mixei

Sampler / remixador estilo MPC para Windows — criado por **Ranariel**.

64 pads em 4 bancos, sequenciador de passos, arranjo com crossfades, time-stretch Rubber Band,
detecção de BPM, mixer com efeitos, gravação de áudio e exportação MP3/WAV/FLAC/OGG.
Interface em Português (Brasil), English, Español e 中文.

**Download:** [última versão](https://github.com/Ranariel/JaMixei/releases/latest) — depois de instalado, o programa se atualiza sozinho.

- Guia completo: [LEIA-ME.md](LEIA-ME.md)
- Novidades da versão: [NOVIDADES.txt](NOVIDADES.txt)
- Compilar: `compilar-windows.bat` (Visual Studio 2022) ou `compilar-mingw-linux.sh` (MinGW no Linux)

Cada push na `main` gera uma versão nova automaticamente (GitHub Actions → Release → jaclipei.com).
